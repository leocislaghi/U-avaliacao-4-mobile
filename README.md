# Biblioteca App

Aplicativo em React Native (TypeScript) para divulgar os livros de uma biblioteca. É preciso fazer login para ver o acervo. Usuários comuns só consultam; o administrador cadastra, altera e remove livros.

## Prompts usados (apoio com IA)

Usei IA apenas como apoio pontual em dúvidas de lógica:

"Como separar na mesma tela o que o usuário comum vê do que só o administrador pode ver?"
"Como reaproveitar o mesmo formulário para cadastrar e para editar um livro?"
"Valide que os campos 'ano' e 'páginas' são numéricos"
"Como pedir confirmação ao usuário antes de remover um livro da lista?"
